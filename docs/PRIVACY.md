# 隐私与安全

## 本机数据

岛仔默认在 `%APPDATA%\DaozaiFork` 保存用户设置、待办、本机日程及提醒设置、饮水记录、置物文件路径、连接元数据、自建大模型的接口地址与模型名称，以及忽略的邮件日程标识。环境变量 `DAOZAI_DATA_DIR` 可指定另一目录。置物架保存原文件路径，不复制文件正文。本机日程不上传到工作日历。

邮箱和日历密码、自建大模型的 API Key 通过 Windows 凭据管理器保存；独立 Gemini 会话使用当前 Windows 用户的 DPAPI 加密。连接元数据中可能包含邮箱地址、账号名称和本机登录文件路径，因此整个数据目录都不适合公开上传。

工资页填写的月薪和作息保存在数据目录的 `salary.txt`，只用于在本机计算金额，不联网、不写入诊断日志。开启「收起时显示金额」后，金额会显示在屏幕顶部。

程序读取收件箱内的邮件以展示正文、提取验证码与日历邀请。当前邮件记录保存在内存中；不要将运行中的内存转储公开分享。

开启邮箱页和验证码显示后，新验证码会在屏幕顶部自动展开预览，最长 30 秒，正文简介仅在本机截取，不发往大模型。预览不依赖普通通知开关；历史邮件、已隐藏的验证码不自动展开。验证码默认从本机收到后 60 秒隐藏，同时受服务器收信满 300 秒和邮件明确有效期的约束；没有可用收信时间时沿用本机计时。主动查看仍可显示 15 秒，隐藏不表示验证码已经失效。

## 网络访问

音乐兼容功能会只读访问汽水音乐、酷狗音乐的本机歌词缓存，以及网易云音乐的本机播放日志和播放队列；酷狗配置仅用于提取歌词目录。只保留歌词、歌曲 ID、歌名、歌手、专辑、公开封面地址、播放状态和时间轴，缺少系统封面时会从网易云图片服务获取专辑缩略图。日志正文、音频签名链接等内容不会保存或上传。网易云原生播放事件不依赖 SMTC 或固定内存地址；必要时仍可对已匹配的网易云、酷狗版本只读获取播放进度。不会修改播放器、读取音频或提取登录信息。启动或运行异常的诊断日志保存在数据目录的 `diagnostics/last-error.log`，不会自动上传。

音乐来源列表由本机媒体会话及上述兼容数据生成，不为枚举来源新增网络请求。选择“自动选择”时按播放状态挑选来源；指定播放器后，只展示和控制该来源，并将其标识保存在设置中。播放器暂时不可用时保持选择并等待它恢复。来源切换本身不会代替用户暂停其他播放器，也不是在线歌词、封面或其他功能的联网开关。

启用对应功能后，程序会联系邮箱 IMAP 服务、工作日历 CalDAV / Exchange ActiveSync 服务、AI 服务额度接口以及歌词服务。连接方式和服务器见源码中的 `mail.rs`、`calendar.rs`、`quota.rs`、`lyrics.rs` 及对应 provider 模块。

点击「检查更新」时，程序会访问 GitHub 的公开发布接口，并在请求头中包含岛仔版本号，不发送本地设置、邮箱或日程数据。选择「下载并安装」会从 GitHub 下载公开安装包至 `%LOCALAPPDATA%\DaozaiFork\Updates`，核对大小及 SHA-256 后替换程序并重启；「浏览器下载」通过默认浏览器打开发布页。

「大模型」设置中填写的服务只在开启「启用大模型」后由各功能使用；请求直接发往填写的地址，不经过系统代理、不跟随跳转。「测试连接」「获取模型列表」使用固定测试问题或查询模型列表。模型返回的推理过程不会展示或保存。

「邮件摘要」默认关闭，需同时开启「启用大模型」和「邮件摘要」并保存后生效。只有打开某封邮件的岛内详情或独立阅读窗口时，才会请求一句话摘要；新邮件到达、列表和通知不会触发。带验证码的邮件不会发送，主题和正文都为空的邮件也不会发送。

摘要请求只包含发件人、主题和正文前 4000 个字符（按 Unicode 字符截断），不额外发送链接列表、收件邮箱或附件；正文中原本包含的信息仍可能出现在截取范围内。任何时刻最多一个请求在执行，等待任务只保留最新一个。摘要仅在内存缓存，失败后只有手动点击才重试；关闭功能后不再发起新请求，已发出的请求可能仍由服务端处理，其迟到结果会被丢弃。邮件内容不会写入摘要日志、诊断文件或错误提示。邮件被视为不可信数据，摘要只按纯文本显示，不执行其中的指令或动作。

程序不使用统一的岛仔云端账号，也没有项目自建的邮件或日程上传后台。第三方服务自身的数据处理政策仍然适用。

## 登录凭据

本机 AI 客户端的登录文件只读使用，不修改原客户端配置或替它刷新登录。独立连接的凭据由岛仔自己的安全存储管理。不要把 Cookie、授权码、登录 JSON、凭据文件、真实邮件或私人日程提交到 GitHub。

## 反馈安全问题

请使用仓库的私密漏洞报告入口，见 [SECURITY.md](../SECURITY.md)。普通 UI 问题可以开公开 Issue，但请先去除敏感信息。
