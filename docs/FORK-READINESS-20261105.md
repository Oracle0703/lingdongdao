## 数据兼容与使用说明

- 新待办仍保存在 `todo.txt`，内容改为版本化 JSON；能读取旧格式。旧程序不能正确读取新格式，请勿把本分支数据目录交给原版使用。
- 饮水改为带 `format=2` 的单文件 `water.txt`，首次读取兼容旧 `water.txt` + `water-extra.txt`；原子保存全部进度，避免两文件只写成一个。
- 核心数据读取失败会提示并禁止保存。修复原文件后重新启动/加载，避免默认空状态覆盖尚未读到的数据。
- 旧 Codex/Kimi 额度条目没有身份指纹时，需要在设置中点击“重新绑定当前登录”。有稳定身份的令牌正常刷新不会改变绑定；缺少身份信息的凭据变化会要求重新确认。Claude Code 不做这项换号检测，沿用上游的当前登录引用行为。
- 同一 UID 连续三次读取失败后，本次服务实例会跳过该邮件，邮件仍保留在服务器上。当前计数尚未区分内容/协议错误和抓取过程中的网络错误，因此持续网络故障也可能触发跳过；可在原邮箱客户端查看，重启服务后会重新尝试最近邮件。
- 所有更新来自自有仓库。安装包仍沿用 `Daozai-Setup-v<版本>-x64.exe` / `Daozai-v<版本>-windows-x64.zip` 文件命名，便于兼容现有更新协议。
